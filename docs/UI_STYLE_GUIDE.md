# 画面のスタイルの決まり

画面の見た目（色・余白・印・リンク・表）の書き方。CSS を書く前、新しい部品を作る前に読む。

- この文書には「どう書くか」だけを書く。決めた理由は設計書（主に 9.1）に書く
- 対象：`plugin/styles.css` と、`views/`・`ui/` のクラスの付け方
- HTMLレポート（`report/htmlReport.ts`）は白地で印刷する別のファイルなので対象外（設計書 13章）

## 1. 基本

- 見た目は `styles.css` のクラスで決める。`el.style` に直接書かない
- TS から渡してよいのは `setCssProps` の `--pm-*` だけ（位置・幅・設定の色など、描くときに決まる値）
- クラス名は `pm-` で始まる kebab-case。状態は `is-*`、依存の印だけ `has-*`
  - 例外：警告の種類（`is-overdueRisk` など）はデータの名前をそのまま使う
  - 例外：負荷の段階（`pm-load-normal` など）は昔からの名前のまま
- まず既存の部品を使えないか考える
  - 5章の印、6章のリンク、`views/badges.ts`・`views/actions.ts`・`views/filterBar.ts`・`ui/controls.ts`・`ui/table.ts`

## 2. 使う値（トークン）

| 何 | 使う値 |
| --- | --- |
| 余白 | `--size-2-2`（印どうしの間）、`--size-4-1`、`--size-4-2`、`--size-4-3`、`--size-4-4` 以上（節の間） |
| 角の丸み | 印・カード・ボタン状のもの → `--radius-s`、囲み枠（パネル）・カンバンの列 → `--radius-m` |
| 文字の大きさ | 印・注意書き・グラフの目盛り → `--font-ui-smaller`、表・絞り込み・凡例 → `--font-ui-small`、ビューの見出し → `--font-ui-large` |
| 文字の太さ | `--font-semibold`（見出し・まとめの行）、`--font-normal` |

- px で書いてよいのは次だけ
  - **1px（や 2px）の線**
  - **ガント・グラフ・カンバン・進捗の棒の寸法**
- 寸法は、その部品の節の先頭で `--pm-*` に名前を付けて使う（例：`.pm-gantt` の `--pm-gantt-row`）

## 3. 色

- テーマの色は Obsidian の変数を使い、hex を書かない
- 意味ごとに1つの色にする

| 意味 | 色 |
| --- | --- |
| 期限超過・誤り・警告（重いもの） | 赤 `--color-red`（`--text-error` は使わない） |
| 遅れ・注意 | 橙 `--color-orange` |
| 完了・対象外・控えめ | 灰 `--text-faint`（文字）、`--background-modifier-border-hover`（棒） |
| 押せるもの・今日・選択 | `--text-accent` / `--interactive-accent` |
| 保存前の変更（入力画面のマス） | 黄 `--color-yellow`（25% の薄い背景。太字も付ける） |
| ガントの縦線（開始日・今日） | 開始日は青 `--color-blue`、今日は緑 `--color-green`（期限日は赤） |

- 設定で変わる色は CSS 変数で受け取る（設計書 6章）
  - 種類の色：`--pm-color-project/epic/task`（`body` に入れる）
  - ステータスの色：印ごとに `--pm-mark-color`
- hex を書いてよいのは、色覚の違いを確かめたグラフの系列色だけ（`.pm-burnup`。設計書 9.5）
- 色だけに頼らず、文字（名前・印の文字）でも分かるようにする

## 4. 薄い背景と線

- 印の薄い背景は1つの値：`color-mix(in srgb, <色> 14%, transparent)`。枠は同じ色の 55%
  - 5章の `pm-mark is-tinted` を使えば自分で書かなくてよい
- 例外：負荷のセルの塗りと負荷率のグラフの棒は段階を表す
  - 12%（正常）・25%（注意）・30%（警告）の3段だけを使う
- 線は2種類だけ
  - 罫線（表・ガント・グラフのマス目）：`--pm-grid-color`（`body` で決めている。うっすら見える濃さ）
  - 部品の区切り（シェルの下・固定した列の境目・カード・ツールチップ）：`--background-modifier-border`

## 5. 小さな印（`pm-mark`）

形は1つ。役割で2種類に分ける。新しい印もこのどちらかにする。

| 種類 | クラス | 見た目 | 使っているもの |
| --- | --- | --- | --- |
| 状態の印 | `pm-mark is-tinted` | 枠＋薄い背景（色は `--pm-mark-color`）、文字は通常の色 | ステータス、警告、休日（社休・個休・土日）、休日稼働 |
| 数・分類の印 | `pm-mark is-plain` | 背景だけ（`--background-modifier-hover`）、枠なし | 絞り込み・フォームのチップ、カンバンの件数、健全性チェックの種類 |

- 共通の形
  - 横の余白 `--size-4-2`、角 `--radius-s`、文字 `--font-ui-smaller`、太さ `--font-normal`
  - 行の高さ 1.5、折り返さない
- 色は CSS で `--pm-mark-color` を決めるか、設定の色なら TS から `setCssProps` で渡す
- 印のクラス（`pm-status`・`pm-badge`・`pm-holiday-mark` など）は目印として残す
  - そこには色や置き場所（左右の余白）だけを書く
- 印を並べる箱は隙間 `--size-2-2`（`pm-badges`）
  - チップの箱（`pm-chips`）だけは × を押しやすいよう `--size-4-1`
- 種類の色の丸（`pm-kind-mark`）とガントの凡例の棒は、「印」ではなく見本なので対象外

## 6. 押せるもの

見せ方は2通りだけ。

| 種類 | クラス | 見た目 | 使う場所 |
| --- | --- | --- | --- |
| 名前のリンク | `pm-link` | アクセント色、乗せると下線 | 表の中でノートやビューを開く名前（メンバー名、エピック名など） |
| 動かすリンク | `pm-action-link` | ふだんは通常の色、乗せるとアクセント色＋下線 | 絞り込んで開く・行へ移動する・編集画面を開く文字や印（警告の印、工数配分の数字、ガントの表示名、健全性チェックの項目、タスクの進捗の値） |

- 行全体を押せる表は `tr.is-clickable`（乗せると行の背景が変わる）
  - その行の中にはリンクを重ねない
  - 例外：警告の印とタスクの進捗の値。押しても行のクリックは動かない
- 開閉の印（`pm-toggle.is-button`）・カンバンのカードは、押せる範囲が広いので背景・枠の色で示す
- 行き先は `aria-label` で出す
- 点線の下線は使わない（見づらいため）

## 7. 表

- `table.pm-table` を使う
  - 見出しを上に固定するので `border-collapse: separate; border-spacing: 0`。罫線はセルごとに引く
  - `collapse` だと見出しの上の線が残り、下の行が透ける
- 見出しはすべて中央（数値の列も）。セルは文字を左、数字を右（`is-numeric`）
- 行全体の文字色を変える指定（`.pm-wbs-task td` など）を足すときは、セルの文字色が負けないか確かめる
  - 表のセルは `.pm-table td.pm-text-…` で強めてある
- 文字色のクラス：`pm-text-error`（赤）、`pm-text-warning`（橙）、`pm-text-faint`（灰）

## 8. 囲み枠・カード

- 囲み枠（絞り込み）
  - 余白 `--size-4-2 --size-4-3`、角 `--radius-m`、背景 `--background-secondary`
- カード（カンバン）・ツールチップ
  - 枠 `--background-modifier-border`、角 `--radius-s`、背景 `--background-primary`

## 9. 重なり順（z-index）

| 値 | 使うもの |
| --- | --- |
| 1 | カンバンの列の見出し、メンバー状況・工数配分・作業ログの入力画面の固定した列のセル、ガントの今日の線・依存の線・開始日と期限日の線 |
| 2 | 表の固定した見出し、ガントの表示名の列、負荷率のグラフの目盛りの行 |
| 3 | メンバー状況の左上（見出しかつ固定した列）、ガントの見出しの行 |
| 4 | ガントの左上 |

新しく重ねるときは、この表に足してから使う。

## 10. styles.css の並び

1. 共通
   - 設定画面 → 罫線の色 → 印（`pm-mark`・種類の丸・休日・警告）→ 文字色 → 表 → シェル
   - → 押せるもの・開閉 → 凡例・注意書き → 進捗の棒
2. 画面ごと
   - WBS → カンバン → プロジェクト状況・メンバー状況 → 絞り込み → 健全性チェック
   - → チップ → グラフ → ガント
   - 作業ログの入力画面は、工数配分のマス目の後ろ（共通のマス目の見た目を使うため）

- 画面だけで使うルールはその画面の節に置く
- 節の頭に1行のコメントで、何の節かと設計書の節番号を書く

## 11. 新しい部品を作るときの確かめ

1. 既存の部品・印・リンクで足りないか
2. 色・余白・角・文字の大きさは 2〜4章の値か（px や hex を書いていないか）
3. 押せるものは 6章のどちらかか。行き先を `aria-label` で出したか
4. ライトとダークの両方のテーマで見たか
5. 色だけで区別していないか

## 12. 節の見出し

ビューの本体の節（`pm-section`）の中の見出しは、階層ごとに大きさを固定する。

| 階層 | 使うもの | 文字の大きさ |
| --- | --- | --- |
| h3 | 節全体のタイトル（プロジェクト状況の概要のプロジェクト名） | `--font-ui-large` |
| h4 | 節の見出し（マイルストーン、エピックとタスク、工数配分など） | `--font-ui-medium` |
| h5 | 節の中の小見出し（進捗グラフの2つのグラフの名前） | `--font-ui-small` |

- 太さは `--font-semibold`、行の高さは `--line-height-tight`。下の余白は `--size-4-2`
- ボタンや切り替えと並べるときは、見出しを `pm-section-head` の行に入れる
  - 行の中の h4 は余白0。行の下の余白 `--size-4-2` だけを使う
- 見出しのすぐ下の注意書き（`pm-note`）は上の余白0、下に `--size-4-2`
- 見出しの大きさを部品ごとに上書きしない。新しい階層が要るときはこの表に足してから使う
