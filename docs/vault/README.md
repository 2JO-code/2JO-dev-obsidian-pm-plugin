# プロジェクト管理の使い方

この Vault では、プロジェクト・タスク・メンバーの作業時間を Obsidian のノートで管理しています。
「Project Manager」プラグインが、**進み具合・遅れ・メンバーの忙しさ** を画面に表示します。

> [!tip] 困ったら
> 左のリボン（縦に並んだボタン）の **かばんのボタン**（プロジェクト管理）を押すと、主な操作がすべて出ます。
> キーボードなら `Ctrl + P` で「Project Manager」と打つと、コマンドの一覧が出ます。

---

## 1. まず知っておくこと

- **1件 = 1ノート** です
  - プロジェクト、エピック（作業のまとまり）、タスク、メンバー、作業ログが、それぞれ1つのノートです
- **ファイル名は ID**（`TASK-019a…` のような文字）です。ファイル名は変えないでください
  - 探すときはタイトルで探せます（`Ctrl + O` でタイトルを打つ）
- タイトルや所属などの情報は、ノートの上にある **プロパティ** に入っています
- **ノートは直接書き換えないでください**
  - 入力や変更は、プラグインの画面（フォーム・編集画面・カンバン）から行います
  - 画面からなら書き方の誤りが起きず、変えたところだけがノートに書き込まれます（5章）
  - 各画面の行や名前をクリックすると、ノートではなく入力の画面（フォーム）が開きます
- 進み具合や負荷などの計算結果はノートに書かれません。画面を開くたびに計算します

### ノートの種類

| 種類 | 中身 | 例 |
| --- | --- | --- |
| プロジェクト | 案件そのもの。期間・責任者・マイルストーン・工数配分 | 新製品プロモーションCG |
| エピック | プロジェクトの中の工程・まとまり | 設計、モデリング |
| タスク | 1人でする具体的な作業。担当者（1人）・期限日・見積 | 主要キャラのモデリング |
| メンバー | 1人1ノート。1日の通常の稼働時間、負荷許容率、個人休日 | 山田 太郎 |
| 作業ログ | メンバー×月ごとの予定・実績の時間の記録 | 山田 太郎の 2026年11月 |

## 2. 毎日の使い方

### 2.1 作業ログを付ける（予定・実績の時間）

1. かばんのボタン →「**作業ログを入力**」
2. 上の欄でメンバーを選ぶと、縦にタスク・横に日付の表が開きます
   - 横は「**1週間**」（月〜日）か「**1か月**」を選べます。前回選んだ方で開きます
   - 「＜」「＞」「今週（今月）」や日付の選択で、期間を替えられます。替えても入力は残ります
   - 自分が担当する終わっていないタスクと、その期間に記録のあるタスクが並びます
   - 「完了・停止した担当タスクも表示」にチェックを入れると、終わった担当タスクも並びます
   - ほかのタスクは、表のいちばん下の「**＋タスクを追加**」で名前で探して足します（★は担当）
   - 上の欄の「すべてのプロジェクト」「すべてのエピック」「すべてのステータス」で、並ぶタスクを絞れます
   - タスクはプロジェクト → エピックの下に並びます。▼ を押すとたたみ、▶ で開きます
   - プロジェクト・エピックの行には、配下のタスクの合計が出ます
   - 「タスク」の見出しの横のボタンで、すべて開く・すべてたたむができます
3. 右上の「**予定**」「**実績**」で入れる方を選び、マスに時間を直接入れる
   - 時間は **0.25 刻み**（15分単位）です。例：1.5。空にすると、その記録を消します
   - マスの右下の小さな数字は、もう片方（予定なら実績）の値です
   - 矢印キー・Enter で隣のマスへ動けます
   - タスク名の右に、参考の **見積(h)** と **月の合計**（例：11月の実績）が出ます
   - タスク名・見積・月の合計は、横に動かしても左に残ります
   - 月の合計は、表に出ていない日も含めたその月全体の時間です。週が月をまたぐと2列出ます
   - 開始日のマスは左端に青い線、期限日のマスは右端に赤い線が出ます
   - 保存する前に値を変えたマスは、黄色の背景と太字になります。保存すると元に戻ります
   - 下の行には日ごとの合計が出ます
   - 表は枠の中で縦に動きます。日付の見出しは上に、日ごとの合計は下に残ります
   - ガントチャートの当初期間に入る日のマスは薄く塗られます
   - 見込みの日程に入る日のマスは、上に色の線が出ます（意味は表の上の凡例）
4. 「**保存**」か「**保存して閉じる**」で、入力したマスをまとめて書き込みます
   - その月の作業ログのノートが無ければ、自動で作られます
   - 保存せずに閉じようとすると、確認が出ます
5. メモを書く・記録をまとめて直すときは、表の下の「**（月）の記録を一覧で編集**」を押す
   - その月の記録が表で開き、日付・タスク・予定・実績・メモを変える、行を足す・消すことができます
   - タスクの欄を押すと、タスク名（かプロジェクト名）で探して選ぶ画面が開きます
   - 日付はその月の中だけです。ほかの月の記録は、行を消して「作業ログを入力」で入れ直します

**タスクから入れる**：**プロジェクト状況** でエピックの ▶ を押してタスクを開き、タスクの行の「**＋工数**」を押します。

- そのタスクの行を足した状態で同じ画面が開き、今日のマスに入ります
- メンバーは、前回選んだ人がそのタスクの担当者ならその人、担当者が1人ならその人が選ばれます

> [!note] 予定と実績
> - **予定**：その日にその作業に使うつもりの時間。メンバーの「負荷率」の計算に使います
> - **実績**：実際に使った時間。「工数超過」（見積より多く使った）の判定に使います

### 2.2 タスクの進み具合を変える

どれかの方法で、タスクの **ステータス** を変えます。

- **カンバン** でカードを別の列へドラッグする（いちばん簡単）
- 各画面のタスクの行やカードをクリックする（入力補助フォーム。選ぶだけで入力できます）

タスクの **説明**（作業の内容や注意など）は、タスクのフォームの「説明」の欄に書きます。

タスクのフォームの「日程」には、入力中の値での **見込みの日程** が出ます。

- 開始日〜期限日が見込みの日程です。片方だけなら、その1日だけになります
- 先行タスクを選んでも、日程は自動ではずれません。先行の終わりに合わせて開始日を入れてください
- 期限日を過ぎるときは赤で出ます。日付や日数を変えると、すぐに出し直します
- 「当初開始日」「当初終了日」には、最初に立てた計画を入れます（両方入れます）
  - 見込みの日程の下に「当初より2日遅れ」のように出ます（稼働日で数えます。遅れは橙）
  - 当初の日付は計画を変えたときだけ書き換えます。日程の計算には使われません

タスクの細かい作業は **チェックリスト** にします。

- タスクのフォームに、項目とチェックの状態が表示されます（多いときは欄の中でスクロール）
- 開き方：タスクのフォームの「**チェックリストを編集**」
  - タスク一覧・WBS・プロジェクト状況の「進捗」の値（例：33%（1/3））を押しても開けます
  - タスクのノートを右クリック →「チェックリストを編集」でも開けます
- 項目を足す・チェックする・消すことができます。入力欄で Enter を押すと、次の項目を足せます
- チェックした割合が、各画面の「進捗」に出ます（タスクが完了のステータスなら「完了」）
- 新しい項目は、今ある項目の下に足されます。並べ替えはできません

一覧の日付が休日のときは、日付の後ろに休日の種類の印が付きます（マウスを乗せると理由が出ます）。

| 印 | 色 | 意味 |
| --- | --- | --- |
| 社休 | 橙 | 会社休日（設定の会社カレンダーの休日） |
| 個休 | 紫 | その行の人の個人休日（2.3）。タスクは担当者のだれか、エピックは担当者、プロジェクトは責任者 |
| 土日 | 灰 | 土曜・日曜（土日を休日にする設定のとき） |

- 会社休日・土日に開始日を置くと、次の稼働日から始まる計算になります
- 個人休日は日程の計算には使いません。負荷の計算では、その人の休みの日になります（2.3）

### 2.3 個人休日（有給など）を入れる

**メンバー状況** の上の「**個人休日を編集**」から自分を選ぶと、休みの日を足す・変える・消すことができます。

- メンバーのノートを右クリック →「個人休日を編集」でも開けます
- 日付を選び、メモ（有給など）は空でもかまいません
- 変えた行だけが、メンバーのノートの「個人休日」の表に書き込まれます
- 一覧の日付に「個休」の印が付きます（メンバー状況には付きません）
- **負荷率の計算では、その人が働かない日として扱います**
  - 働ける時間（基準）がその日の分だけ減ります。単位が「日」のメンバー状況では「—」になります
  - 工数配分は、休みの日を除いた日に割り振ります（月の合計は変わりません）
  - 休みの日に作業ログが入っていると、「休稼」（休日稼働）になります
- タスクの日程（見込みの日程）の計算には使いません

### 2.4 ノートを作る

かばんのボタン →「新しいプロジェクト」「新しいエピック」「新しいタスク」「新しいメンバー」。

- ID や必要なプロパティは自動で入ります
- メンバーは氏名・姓・名をそれぞれ入れます。ガントチャートの担当者には姓が出ます
- まだ決まっていないプロパティ（開始日・担当者など）も、空の欄としてはじめから並びます
- 各画面の上の「新しいタスク」などのボタンからも作れます（絞り込んでいるプロジェクトが選ばれます）
- 作ってもノートは開かず、画面の右上に「作成しました」と出ます。作ったものは各画面にすぐ出ます

前に作ったプロジェクトをひな形にするとき：かばんのボタン →「**プロジェクトを複製**」。
ダッシュボードの上のボタンからも開けます。

- 元のプロジェクトを選び、新しい名前・案件ID・正式案件名を入れて「作成」を押します
- エピック・タスクの並びとWBS番号、見積工数、先行タスク、説明とチェックリストが写ります
- 担当者・責任者・工数配分・作業ログは写りません。ステータスは最初のもの、チェックは外れた状態になります
- 日付は「開始日に合わせてずらす」か「空にする」を選びます
  - ずらすと、元の開始日からの稼働日数を保ったまま、新しい開始日に合わせて全部の日付が動きます
  - マイルストーンもずらして写ります。「空にする」ではマイルストーンは写りません
- 終わったプロジェクト（アーカイブ内も）も元にできます

作ったあとの入力：

| 何を | どこから |
| --- | --- |
| エピックの担当者・開始日・期限日・インプット・アウトプットなど | **プロジェクト状況** のエピックのタイトルをクリック（WBS・ガントチャートも同じ） |
| メンバーの氏名・姓・名・1日の通常稼働時間・負荷許容率・在籍 | **メンバー状況**・**ダッシュボード** のメンバー名をクリック |
| プロジェクトの名前・案件ID・ステータス・期間・責任者 | **プロジェクト状況** の上の「**フォームで編集**」 |
| マイルストーン・工数配分 | **プロジェクト状況** のそれぞれの見出しの横の「**編集**」、または行・配分の数字をクリック |

- メンバー・プロジェクトのフォームは、ノートを右クリック →「入力補助フォームで編集」でも開けます
- エピックのプロジェクトは、タスクやマイルストーンの連動が無いときだけ変えられます（作り間違えの直し用）
- マイルストーンは、行を変える・足す・消す画面です
- 工数配分は、縦にメンバー・横に月の、エクセルのようなマス目に配分(h)を入れる画面です
  - プロジェクトの期間の月と、配分か作業ログのあるメンバー・責任者が最初から並びます
  - メンバーは表の左下の「＋メンバー」、月は表の右上の月の欄で選ぶと、すぐ足されます
  - マスを空にするとその配分を消します
  - 行の右端のごみ箱で、その人の配分をまとめて消せます。消す前に確認が出ます
  - 月ごとに「配分・予定・実績」の3列です。入力できるのは配分だけです
  - 予定・実績は、その月・メンバーの作業ログの合計（参考）です。予定が配分を超えると赤になります
  - 矢印キー・Enter（下へ）・Shift+Enter（上へ）でマスを移動できます
- どの画面も、変えたところだけがノートに書き換わります

## 3. 画面（ビュー）の一覧

どれも、かばんのボタンから開けます。どの画面も上の部分は同じ並びです。

1. 画面の名前と一行の説明（右に件数）
2. **絞り込み**（プロジェクト・担当者・ステータスなど。タブを閉じるまで覚えています）
3. 左に **表示の設定**（単位・グループ・「罫線を表示」など）、右に **操作のボタン**（新しいタスクなど）
4. 色や印の意味（凡例）と注意

| 画面 | 何が分かるか |
| --- | --- |
| **ダッシュボード** | 全プロジェクトの進捗・工数・警告、メンバーの負荷（配分・予定・実績）、2週間以内のマイルストーン |
| **タスク一覧** | タスクを表で一覧。並べ替え・グループ分け |
| **カンバン** | ステータスごとの列にタスクのカード |
| **WBS** | プロジェクト → エピック → タスクの階層と、見込みの日程 |
| **ガントチャート** | 日程の棒グラフ。開始日・期限日・マイルストーン・今日の線 |
| **作業ログ** | タスクごと・日ごとの予定と実績の時間（見るだけ） |
| **メンバー状況** | メンバーごとの負荷（全プロジェクトの合計）。配分・予定・実績を、%か時間で |
| **メンバーダッシュボード** | 1人の、月ごとのアサイン案件と担当タスク。見たい画面を組み合わせて自分用にできる |
| **プロジェクト状況** | 1つのプロジェクトの概要・進捗グラフ・マイルストーン・エピックとタスク・工数配分 |
| **警告一覧** | ノートの書き方の誤り、ファイル名が ID の形でないファイル |

### ダッシュボード

- 行をクリックすると各画面へ
- メンバーの負荷率の横棒グラフ（在籍者全員）
  - 「値」で配分・予定・実績を選びます（はじめは配分）。負荷はまず配分で見て、予定・実績で確かめます
  - 「数値」で負荷率(%)・工数(h)を選びます。工数でも色は負荷率で付きます
  - 縦の線が100%、黒い印がその人の負荷許容率。緑＝100%以下、橙＝負荷注意、赤＝負荷警告
  - 工数(h)では、100%の線（働ける時間）は人ごとに引きます
  - 値や数値を切り替えても、目盛りと100%の線の位置は変わりません
  - 期間は「今週・来週・今月・来月」、並び順は「名前順・負荷率の高い順・低い順」から選ぶ
  - メンバー名はメンバーのフォーム、棒はメンバー状況を開く
- グラフにマウスを乗せると値が出ます（負荷率の棒は配分・予定・実績の時間と働ける時間）
- HTMLレポートの書き出し（6章）

### タスク一覧・カンバン

- タスク一覧：行をクリックでタスクのフォームを開く
  - 「当初差」の列で、当初終了日からの遅れ（「3日遅れ」など）が分かります。見出しを押すと遅れの順
- カンバン：カードを列へドラッグでステータスを変える。クリックでタスクのフォームを開く
  - 「列の幅」のつまみ・「画面の幅に合わせる」で列の幅を変える

### WBS・ガントチャート

- 行の先頭の ▶／▼ を押して開け閉め（プロジェクト状況も同じ）
- ガントの棒の色は種類ごとの色（7章）。単位が「日」のときは休日の列がグレー
- ガントで棒にマウスを乗せると依存関係の線。単位（日・週・月）を切り替えられます
- ガントの名前と日付の間の「担当者」の列に、エピック・タスクの担当者の姓が出ます（指すと氏名）
  - 「担当者を表示」で出し入れできます
- ガントの「タイトル」の列の幅は、見出しの「タイトル」の右端をドラッグして変えられます（ダブルクリックで元の幅）
- ガントのタスクの行には、当初期間が棒の後ろに薄い帯で出ます。棒がはみ出していれば当初の計画からずれています
- ガントの青い縦線は開始日、赤い縦線は期限日、緑の縦線は今日です
- 依存関係のあるタスクには ⇆ の印。「依存の印を表示」で出し入れできます
- ガントの「作業ログ」で、日のマスに作業ログの時間を出せます（単位が「日」のときだけ）
  - 「実績」「予定」「予定と実績」から選びます。「予定と実績」では上が予定、下が実績です
  - 出しているあいだは棒が薄くなります。エピック・プロジェクトの行は配下の合計です
  - 赤い数字は、棒の期間の外で付けた実績です。数字を指すと予定と実績が出ます
- エピック・タスクの名前をクリックで入力補助フォームを開く
- プロジェクトの行の「＋エピック」でエピックを、エピックの行の「＋タスク」でタスクを作る
- タスクにも WBS 番号が付きます（例：エピックが 1.2 なら 1.2.1、1.2.2…）。新しいタスクには続きの番号
- エピック・タスクの行をドラッグすると、順番と番号を入れ替えられます（プロジェクト状況でも同じ）
  - ガントでは左の名前の欄をつかんでドラッグします
  - 落とした行の上半分なら前、下半分なら後ろに入ります（青い線が出ます）
  - エピックは同じプロジェクトの中、タスクは同じエピックの中だけで動かせます
  - タスクの番号は、タスクのフォームの「WBS番号」でも直せます

### 作業ログ

- ガントチャートと同じ並びで、日ごとの予定・実績の時間を見られます。ここでは直せません
- 「担当者」の列には、記録した人の姓が出ます
  - 2人以上が記録したタスクだけ、下に人ごとの行が出ます
- 「表示する値」で「予定と実績」「実績のみ」「予定のみ」を切り替えます
  - 予定と実績のときは、日の中の「予」（薄い文字）と「実」の2列に出ます
- 「期間」で1週間・1か月を切り替え、「◀ ▶」「今週（今月）」や日付の選択で動かします
- プロジェクト・エピックの行と、いちばん下の「日の合計」には、配下の合計が出ます
  - 「日の合計」は、縦に動かしても画面の下に残ります
- 「記録の無い担当タスクも表示」で、まだ時間を入れていない担当のタスクも並びます
  - 横の「完了・停止したタスクも含める」で、終わった担当タスクも並びます
- 上の「ステータス」で、並ぶタスクを絞れます
- 担当者の右に、参考の **見積(h)** が出ます。プロジェクト・エピックの行は配下の合計です
- タスクの行の後ろに、ガントチャートと同じ当初期間の枠と、見込みの日程の棒が薄く出ます
  - 開始日は青、期限日は赤の縦線です
  - 棒を指すと、日付・当初との差が出ます
- タスクの名前を押すと、その人・そのタスク・その期間で「作業ログを入力」の画面が開きます
- タスクの行の日の欄を押すと、その日のマスに入った「作業ログを入力」の画面が開きます
  - 「予定のみ」「実績のみ」で見ているときは、画面もその値の入力で開きます

### メンバー状況

- 上の「表示」で配分・予定・実績、「数値」で負荷率(%)・工数(h)を選びます（はじめは配分・負荷率）
  - 配分は、各プロジェクトの工数配分（月×メンバー）の合計です
  - 週・日では、月の配分をその人のその月の勤務日数で割って、期間の分を出します
  - 工数(h)でも、マスの色は負荷率で付きます
- マスにマウスを乗せると、配分・予定・実績の時間と基準の時間が出ます
- マスをクリックでプロジェクト別の配分・予定・実績の内訳
- メンバー名をクリックでメンバーのフォーム（メンバーの情報を変える）
- 「個人休日を編集」で休みの日を入力（2.3）

### メンバーダッシュボード

自分（またはだれか1人）の、その月の仕事をまとめて見る画面です。来月のアサインもここで分かります。

- 上の「メンバー」で人を、「月」の ◀ ▶・月の選択・「今月」で月を選びます
- 下に「部品」が並びます。どれも、選んだ人・選んだ月の分だけを出します
  - **月の負荷**：その月の配分・予定・実績の時間と負荷率
  - **アサインされている案件**：その月に工数配分がある案件。行を押すとプロジェクト状況が開きます
  - **タスク一覧**：その月にかかる担当タスク（完了も含む）。「月の予定・月の実績」の列つき
  - **作業ログ**・**ガントチャート**・**カンバン**・**WBS**：それぞれの画面を、その人・その月に絞ったもの
- 「その月にかかる担当タスク」は、見込みの日程がその月に入るか、その月に作業ログを付けたタスクです
- 部品の中の絞り込み・並べ替え・開閉などは、ふだんの画面と同じに使えます
  - ふだんの画面とは別に覚えるので、ここで変えてもふだんの画面は変わりません
- 「**部品を選ぶ**」で、出す部品・並び順・見せ方を選べます
  - 見せ方：「縦に並べる」か「タブで切り替える」
  - ↑・↓ で並べ替え、スイッチで出す・出さないを選びます
  - この選び方は自分のパソコンにだけ残ります。ほかの人には影響しません

### プロジェクト状況

- 一番上に概要。その下に「進捗グラフ」「マイルストーン」「エピックとタスク」「工数配分」の節が並びます
  - 節の並び順と表示する・しないは、個人の設定で変えられます（7章）
- 「進捗グラフ」は「工数の累積」と「進捗率」のグラフを横に並べます。チェックで出し入れできます
  - マウスを乗せると、その日の値が出ます。画面が狭いときは上下に並びます
- 「エピックとタスク」の見出しの横の「新しいエピック」「新しいタスク」で、このプロジェクトに作れます
- エピックの行の ▶／▼ を押してタスクを開け閉め
- タスクは WBS 番号順。エピック・タスクの行をドラッグすると番号を入れ替えられます（WBS と同じ）
- エピックのタイトルをクリックで、担当者・開始日・期限日を入力。タスクの行のクリックでタスクのフォーム
- タスクの行の「＋工数」でそのタスクの作業ログを入力（2.1）
- 上の「フォームで編集」でプロジェクトのプロパティ、マイルストーン・工数配分の「編集」で表を変える
  - マイルストーンの行や、配分の数字をクリックしても、その表の編集画面が開きます

### 警告一覧

- 行をクリックで、直す画面（入力補助フォーム、表の編集画面）を開く
- 直す画面が無いもの（プロパティが読めないほど崩れたものなど）だけ、クリックでノートを新しいタブで開く

> [!tip] 色の意味（日程）
> - **赤**：期限日より後に終わりそう、または期限日を過ぎている
> - **橙**：遅れを反映して日程をずらしている
> - **薄い色**：完了・停止したもの

## 4. 言葉の意味

| 言葉 | 意味 |
| --- | --- |
| 進捗率 | 完了したタスクの数 ÷ タスクの数。保留・中止のタスクは数えません |
| 見積・予定・実績 | 見積＝タスク全体でかかる見込みの時間。予定・実績＝作業ログの合計 |
| 進捗率のグラフ | 青い線は、その日までに終わるはずのタスクの割合（予定）。橙の点は、今日の実際の進捗率。点が線より下なら遅れ。過去の実際の進捗率は記録しないので、点は今日の分だけ |
| 工数の累積のグラフ | 予定と実績の時間を日ごとに積み上げた線。実績の線が予定より下なら、予定ほど作業が進んでいない（か、時間をかけずに済んでいる）。予定の線が見積の線を超えそうなら、見積が足りない |
| 負荷率 | 配分・予定・実績の時間 ÷ 働ける時間（勤務日 × 1日の通常稼働時間）。100% を超えると「負荷注意」、負荷許容率を超えると「負荷警告」 |
| 配分 | プロジェクト状況の「工数配分」に入れた、月ごと・メンバーごとの時間。負荷を見るときの基本です |
| 稼働日 | 会社カレンダーの休日（土日・祝日など）以外の日。日程の計算に使います |
| 勤務日 | 稼働日のうち、その人の個人休日でない日。負荷率の計算に使います（2.3） |
| 先行タスク | そのタスクより先に終わらせる必要のあるタスク。ガントに印と線で出ます。日程は自動ではずれません |
| 見込みの日程 | 開始日・期限日と遅れから計算した開始日・終了日。ノートには書かれません |
| 当初差 | 見込み終了日が、当初終了日より何稼働日遅れているか（早いか） |
| マイルストーン | プロジェクトの節目の日（中間レビュー、納品など）。プロジェクト状況のマイルストーンの「編集」から入れます |
| クローズ | プロジェクトのステータスを「クローズ」にすると、終わったプロジェクトとして普段の画面から外れます |

### 警告の種類

警告は種類ごとの小さな印（［期限超過 1］など）で出ます。色は種類の目安で、名前が書いてあります。

- ダッシュボード・プロジェクト状況・WBS の警告の印をクリックすると、警告の出ているタスクだけをタスク一覧で開けます
- 配分超過は、プロジェクト状況の工数配分の表で確かめます

| 警告 | 出る条件 | 直し方の例 |
| --- | --- | --- |
| 期限超過 | 期限日を過ぎたのに完了していない | 終わっていれば完了に。終わっていなければ期限日を相談して変える |
| 期限超過見込み | 開始日が期限日より後になっていて、見込み終了日が期限日を過ぎる | 開始日・期限日を見直す |
| 工数超過 | 実績の合計が見積を超えた | 見積を見直す |
| 配分超過 | プロジェクトのある月・ある人の予定が、工数配分を超えた | 予定を減らすか、配分を見直す |
| 負荷注意・負荷警告 | メンバーの予定が多すぎる | 予定を別の人・別の日に移す |
| 休日稼働 | 休日に予定・実績が入っている（メンバー状況のセルに「休稼」の印） | 意図したものか確かめる |

## 5. SVN で使うときの約束

この Vault は SVN で全員と共有しています。ぶつかり（コンフリクト）を防ぐため、次を守ってください。

1. **作業を始める前に「SVN 更新」**、終わったら **「SVN コミット」**（TortoiseSVN の右クリックメニュー）
2. **同じタスクを複数人で同時に編集しない**
3. ノートを **エクスプローラーで移動・名前変更しない**（履歴が途切れます）。移動は TortoiseSVN の「移動」で
4. **ノートは直接書き換えず、プラグインの画面から変える**（1章）
   - 作業ログ：「作業ログを入力」かタスクの行の「＋工数」（まとめて直すときは「記録を一覧で編集」）
   - タスク・エピック・プロジェクト・メンバー：各画面の行や名前のクリックで開くフォーム（タスクの説明も）
   - マイルストーン・工数配分：プロジェクト状況の「編集」
   - 個人休日：「個人休日を編集」。チェックリスト：「チェックリストを編集」
   - ノートの表を手で編集すると、Obsidian が表全体の空白を整え直し、全部の行が変わったことになります
   - ほかの人の変更とぶつかりやすくなります

## 6. ときどき使う機能

### HTMLレポート（上司などへの共有）

SVN を使わない人にも状況を見てもらうための、ブラウザで開ける1つのファイルです。

1. 出力先を決める（最初の1回だけ）
   - 設定 → Project Manager →「このパソコンだけの設定」→「HTMLレポート」の「**出力先**」
   - 共有フォルダ（例：`\\server\share\pm-report`）を入れる
2. かばんのボタン（またはダッシュボードのボタン）→「**HTMLレポートを書き出す**」
3. 出力先の `project-report.html` を開く。クローズしていない全プロジェクトの状況が入っています
   - メンバー全員の負荷率（今週・今月の配分・予定・実績、来月の配分・予定）も入っています

### アーカイブ（終わったプロジェクトの片付け）

1. プロジェクトのステータスを「クローズ」にする
2. かばんのボタン →「**アーカイブ対象の一覧**」で、動かすファイルと移動先を確かめる
3. 画面の手順に従い、**TortoiseSVN の「移動」** でアーカイブフォルダへ動かしてコミットする
   - プラグインはファイルを動かしません

### 画面がおかしいとき

- 画面の数字が古い気がする：リボンの **↻ のボタン**（データを再読み込み）
- 警告一覧に誤りが出ている：行をクリックして開いた画面で直して保存する
  - 画面が無いものはノートが新しいタブで開くので、書かれている内容を直す
- 警告一覧に「ファイル名が ID の形でない」と出ている：作りかけや、コピーでできたファイルです
  - 不要なら TortoiseSVN の「削除」で消してコミットする
  - 必要な内容なら、プラグインの作成コマンドで作り直して中身を移す
- それでも直らない：`Ctrl + Shift + I` → 「Console」に出る赤い文を、管理者に送ってください

## 7. 個人の設定

設定 → Project Manager の「**このパソコンだけの設定**」。見出し（▶／▼）を押すと開け閉めできます。

| グループ | 設定 | 内容 |
| --- | --- | --- |
| 表示 | プロジェクトの表示名 | 画面でプロジェクトを、簡易名・案件ID・正式名のどれで表示するか |
| プロジェクト状況の節 | 並び順・表示 | 概要の下の4つの節を ↑・↓ で並べ替え、スイッチで表示する・しないを選ぶ。「初期の並びに戻す」で元どおり |
| HTMLレポート | 出力先 | 6章を参照 |

メンバーダッシュボードの部品の選び方は、その画面の「部品を選ぶ」で変えます（3章）。

「**全員共通の設定**」（ステータス・会社カレンダー・種類ごとの色・フォルダ）は **全員に影響します**。
変えるときは管理者に相談してください。

- 種類ごとの色：プロジェクト・エピック・タスクの色
  - ガントチャートの棒と、各画面のタイトルの前の小さな丸（●）に使います
  - ガントの棒は、遅れ（橙）・期限より後（赤）・完了（グレー）のときはその色が優先されます
- ステータスごとの色：ステータスの行の色を選ぶ欄で決めます
  - 各画面の表と HTMLレポートで、ステータスがその色の枠で囲まれます
  - 選んでいないステータスは分類ごとの色（未着手系＝灰、進行中系＝青、完了系＝緑、停止系＝橙）
  - ↺ のボタンで分類の色に戻せます
