PROJECT MANAGER for Obsidian

プロジェクト管理の使い方

プロジェクト・タスク・メンバーの作業時間を Obsidian のノートで管理し、進み具合・遅れ・メンバーの忙しさを画面に表示します。

START かばんのボタン左のリボンにあります。主な操作はすべてここから。メニューの「ツールバーを開く」で、左のサイドバーにボタンとして並べられます。Ctrl+P→「Project Manager」でも出ます。
EVERY DAY作業ログを付ける予定と実績の時間を入れます（2.1）。
ON CHANGEステータスを変えるカンバンでカードを別の列へドラッグ（2.2）。

1まず知っておくこと

  • ファイル名は ID（TASK-019a…）。変えないでください。探すときはタイトルで（Ctrl+O）
  • タイトルや所属は、ノートの上の プロパティ に入っています
  • 進み具合や負荷などの計算結果はノートに書かれません。画面を開くたびに計算します
ノートは直接書き換えないでください

入力や変更は、プラグインの画面（フォーム・編集画面・カンバン）から行います。書き方の誤りが起きず、変えたところだけがノートに書き込まれます（5章）。各画面の行や名前をクリックすると、入力の画面が開きます。

2毎日の使い方

2.1作業ログを付ける（予定・実績の時間）

かばんのボタン →「作業ログを入力」→ メンバーを選ぶと、縦にタスク・横に日付の表が開きます。

  • 並ぶのは、自分が担当する終わっていないタスクと、その期間に記録のあるタスク。上の欄でプロジェクト・エピック・ステータスを絞れます
  • 担当でないタスクには入れられません。手伝ったときは、自分が担当のタスクを作って入れます
  • 「完了・停止した担当タスクも表示」で、終わった担当タスクも並びます
  • 矢印キー・Enter で隣のマスへ。月の合計は表に出ていない日も含めた値です
  • 保存すると、その月の作業ログのノートが無ければ自動で作られます。保存せずに閉じると確認が出ます
  • タスクから入れる：プロジェクト状況のタスクの行の「＋工数」→ 担当者の、そのタスクの今日のマスで開きます。担当者がいないタスクでは押せません
予定と実績
  • 予定：使うつもりの時間 → メンバーの「負荷率」に使います
  • 実績：実際に使った時間 → 「工数超過」（見積より多く使った）の判定に使います

2.2タスクの進み具合を変える

  • ステータス：カンバンでカードを別の列へドラッグ（いちばん簡単）か、タスクの行・カードのクリックで開くフォームで
  • 説明（作業の内容や注意）：タスクのフォームの「説明」の欄
  • 終了日（実際に終わった日）：完了にするとき「終了日を今日にしますか？」と聞かれます
    • 「今日にする」で今日の日付が入ります。「変えない」なら今の値のままです
    • 別の日に終わったときは、タスクのフォームの「終了日」の欄で直します
    • 完了から別のステータスに戻しても、終了日は消えません

見込みの日程の見え方

  • 日程の欄は、当初開始日・当初終了日 → 開始日・終了日 → 期限日の順。見出しの右の印はガントの印と同じです
  • 開始日〜期限日が見込みの日程。片方だけなら、その1日だけ。値を変えるとすぐ出し直します
  • 先行タスクを選んでも日程は自動ではずれません。先行の終わりに合わせて開始日を入れてください
  • 期限日が休日なら、橙で注意が出ます（そのまま保存も可。エピック・プロジェクトも同じ）
  • 「当初開始日」「当初終了日」は最初の計画。計画を変えたときだけ書き換えます（日程の計算には使いません）
  • 完了したタスクに終了日があれば、開始日〜終了日が実際の日程として出ます（「（終了）」と付きます）。ガントの棒や当初との差も、その日で出ます

チェックリスト

  • 開き方：タスクのフォームの「チェックリストを編集」、各画面の「進捗」の値、ノートの右クリック
  • 入力欄で Enter を押すと次の項目を足せます。新しい項目は下に足されます（並べ替えは不可）
  • タスクが完了のステータスなら「完了」と出ます

休日の印

一覧の日付が休日のときは、日付の後ろに印が付きます（マウスを乗せると理由が出ます）。

社休会社休日（設定の会社カレンダーの休日）
個休その行の人の個人休日（タスクは担当者、エピックは担当者、プロジェクトは責任者）
土日土曜・日曜（土日を休日にする設定のとき）

会社休日・土日に開始日を置くと、次の稼働日から始まる計算になります。

2.3個人休日（有給など）を入れる

メンバー状況 の上の「個人休日を編集」（またはメンバーのノートを右クリック）で、休みの日を足す・変える・消すことができます。メモは空でもかまいません。

2.4ノートを作る

かばんのボタン →「新しいプロジェクト」「新しいエピック」「新しいタスク」「新しいメンバー」「新しいスプリント」。各画面の上のボタンからも作れます。

  • ID や必要なプロパティ（空の欄も）は自動で入ります。メンバーは氏名・姓・名を入れます（ガントには姓が出ます）
  • タスクは、編集と同じタスクのフォームが開きます。担当者・日程・見積工数・説明までまとめて入れて「作成」を押します。キャンセルすれば何も作られません
  • タスクのチェックリストは、作成したあとにタスクを開き直して編集します
  • 作ってもノートは開かず、右上に「作成しました」と出ます。作ったものは各画面にすぐ出ます

プロジェクトを複製する

かばんのボタン（またはダッシュボード）→「プロジェクトを複製」→ 元を選び、新しい名前・案件ID・正式案件名を入れて「作成」。終わったプロジェクト（アーカイブ内も）も元にできます。

写る
  • エピック・タスクの並びと WBS 番号
  • 見積工数・先行タスク
  • 説明とチェックリスト（チェックは外れる）
  • マイルストーン（日付をずらすときだけ）
写らない
  • 担当者・責任者
  • 工数配分・作業ログ
  • ステータス（最初のものになる）

日付は「開始日に合わせてずらす」（稼働日数を保って全部動く）か「空にする」を選びます。

作ったあとの入力

何をどこから
エピックの担当者・日付などプロジェクト状況・WBS・ガントのエピックのタイトルをクリック
メンバーの情報メンバー状況・ダッシュボードのメンバー名をクリック
プロジェクトの情報プロジェクト状況の「フォームで編集」
スプリントの期間・ゴールスプリントの画面の列の上の「編集」
マイルストーン・工数配分プロジェクト状況の見出しの横の「編集」、または行・数字をクリック
  • 月は表の右上の月の欄で足します。マスを空にするとその配分を消します
  • 矢印キー・Enter（下へ）・Shift+Enter（上へ）でマスを移動できます
  • エピックのプロジェクトは、タスクやマイルストーンの連動が無いときだけ変えられます（作り間違えの直し用）

いらないタスクを消す

タスクのフォームの下の「タスクを削除」→ 確認画面で「削除」。

  • 作業ログに記録があるタスクと、ほかのタスクの先行タスクになっているタスクは消せません。消せない理由が右上に出ます
  • 使わなくなったタスクは、消さずにステータスを「停止」にしてください（記録が残り、進捗の計算から外れます）
  • 消したタスクは Vault のごみ箱（.trash フォルダ）に移ります（5章）

3画面（ビュー）の一覧

どれも、かばんのボタンか、左のサイドバーのツールバーから開けます。どの画面も上の部分は同じ並びです。

ツールバーは、かばんのボタンの「ツールバーを開く」で、エクスプローラーの隣のタブに出ます。上の段のアイコンでノートの作成と作業ログの入力、下の一覧で画面の切り替えができます。今見ている画面の行に色が付きます。

ダッシュボード全プロジェクトの進捗・警告、メンバーの負荷、2週間以内のマイルストーン タスク一覧タスクを表で一覧。並べ替え・グループ分け カンバンステータスごとの列にタスクのカード スプリントスプリントごとの列にタスクのカードと依存の線 WBSプロジェクト → エピック → タスクの階層と日程 ガントチャート日程の棒グラフ 作業ログタスクごと・日ごとの予定と実績（見るだけ） メンバー状況メンバーごとの負荷（全プロジェクトの合計） メンバーダッシュボード1人の、その月の案件とタスク プロジェクト状況1つのプロジェクトの概要・グラフ・タスク・配分 警告一覧ノートの書き方の誤り、ID の形でないファイル

ダッシュボード

  • 「値」で配分・予定・実績、「数値」で負荷率(%)・工数(h)を選びます。まず配分で見て、予定・実績で確かめます
  • 期間は今週・来週・今月・来月。並び順は名前順・負荷率の高い順・低い順
  • メンバー名でメンバーのフォーム、棒でメンバー状況が開きます。行をクリックすると各画面へ

タスク一覧・カンバン

  • タスク一覧：行のクリックでフォーム。「当初差」の列で当初終了日からの遅れ（「3日遅れ」など）が分かります
  • カンバン：カードを列へドラッグでステータスを変える。完了の列へ動かすと、終了日を今日にするか聞かれます。「列の幅」のつまみで列の幅を変えられます

スプリント

1つのプロジェクトを、期間で区切った「スプリント」ごとに見る画面です。上の「プロジェクト」で選びます。

  • 列は左から「未割り当て」と、スプリント（開始日の順）。列の上に期間・ゴール・見積の合計・完了の数が出ます。進行中の列は上に色の線が付きます
  • カードを別の列へドラッグすると、そのタスクのスプリントが変わります。期限日などの日付は変わりません
  • 期限日がスプリントの期間の外なら、カードに「スプリント」の印が付きます
  • 先行タスクと後続タスクは矢印の線で結ばれます。赤い線は、先行タスクが後のスプリントか未割り当てにある（順番が逆）しるしです
  • カードにマウスを乗せると、そのカードの線だけが濃くなります。線の形は表示の設定の「線の形」で「直角」「曲線」から選べます
  • つながったタスクのまとまりごとに行が分かれます。同じ列の中でつながったタスクは、先行タスクが左に並びます
  • スプリントは「新しいスプリント」で作ります。名前・期間は前のスプリントの続きが初めから入ります。タスクのフォームの「スプリント」の欄でも選べます
  • タスクが入っているスプリントは削除できません。先にタスクを別の列へ動かしてください

WBS・ガントチャート

  • ▶／▼ で開け閉め。単位（日・週・月）を切り替えられます。「担当者を表示」「依存の印を表示」で出し入れ
  • 担当者の右の列に、プロジェクト・エピック・タスクのステータスが出ます
  • 「タイトル」の列の幅は見出しの右端をドラッグ（ダブルクリックで元の幅）
  • 「作業ログ」で日のマスに予定・実績の時間を出せます（単位「日」のみ）。赤い数字は棒の期間外の実績
  • 名前のクリックでフォーム。プロジェクトの行の「＋エピック」、エピックの行の「＋タスク」で作れます

作業ログ

ガントチャートと同じ並びで、日ごとの予定・実績の時間を見る画面です（ここでは直せません）。

  • 「表示する値」で予定と実績・実績のみ・予定のみ。予定と実績のときは「予」（薄い文字）と「実」の2列
  • 担当者以外も記録したタスクは、下に人ごとの行が出ます。「日の合計」は画面の下に残ります
  • 「記録の無い担当タスクも表示」「完了・停止したタスクも含める」で並ぶタスクを増やせます
  • タスクの名前や日の欄を押すと、その条件で「作業ログを入力」が開きます。人ごとの行があるタスクは、人の行を押します

メンバー状況

  • 「表示」で配分・予定・実績、「数値」で負荷率(%)・工数(h)。色はいつも負荷率で付きます
  • 週・日の配分は、月の配分をその人の勤務日数で割って出します
  • マスを指すと時間の内訳、クリックでプロジェクト別の内訳。メンバー名でメンバーのフォーム

メンバーダッシュボード

1人の、その月の仕事をまとめて見る画面です。来月のアサインもここで分かります。上でメンバーと月を選びます。

  • 「その月にかかる担当タスク」＝見込みの日程がその月に入るか、その月に作業ログを付けたタスク
  • 「部品を選ぶ」で出す部品・並び順・見せ方（縦に並べる／タブで切り替える）を選べます。自分のパソコンにだけ残ります

プロジェクト状況

  • エピックのタイトルで担当者・日付を入力、タスクの行でタスクのフォーム、「＋工数」で作業ログを入力（2.1）
  • エピック・タスクの行をドラッグすると番号を入れ替えられます（WBS と同じ）

警告一覧

行のクリックで、直す画面が開きます。直す画面が無いもの（プロパティが読めないほど崩れたものなど）だけ、ノートが新しいタブで開きます。

4言葉の意味

負荷率

2つのグラフ（プロジェクト状況）

そのほかの言葉

進捗率完了したタスクの数 ÷ タスクの数（保留・中止は数えない）
見積・予定・実績見積＝タスク全体の見込みの時間。予定・実績＝作業ログの合計
配分工数配分に入れた月ごと・メンバーごとの時間。負荷を見るときの基本
稼働日／勤務日稼働日＝会社の休日以外の日（日程の計算に使う）。勤務日＝稼働日からその人の個人休日を除いた日（負荷率に使う）
先行タスク先に終わらせる必要のあるタスク。日程は自動ではずれません
見込みの日程開始日・期限日と遅れから計算した日程。ノートには書かれません
当初差見込み終了日が当初終了日より何稼働日遅れているか（早いか）
マイルストーンプロジェクトの節目の日（中間レビュー、納品など）
クローズ終わったプロジェクトのステータス。普段の画面から外れます

警告の種類

警告は 期限超過 1 のような印で出ます。印をクリックすると、警告の出ているタスクだけをタスク一覧で開けます。

警告出る条件直し方の例
期限超過期限日を過ぎたのに完了していない終わっていれば完了に。でなければ期限日を相談
期限超過見込み見込み終了日が期限日を過ぎる開始日・期限日を見直す
上位の期限超過見込み中のタスクがエピック・プロジェクトの期限日より後に終わりそう（印を指すと原因のタスク）タスクの日程か上位の期限日を見直す
工数超過実績の合計が見積を超えた見積を見直す
配分超過ある月・ある人の予定が工数配分を超えた（工数配分の表で確認）予定を減らすか、配分を見直す
負荷注意・負荷警告メンバーの予定が多すぎる予定を別の人・別の日に移す
休日稼働休日に予定・実績が入っている（「休稼」の印）意図したものか確かめる

5全員で使うときの約束

この Vault は全員が同じものを開いています。ほかの人の変更を消さないため、次を守ってください。

  1. 同じノートを複数人で同時に変えるのは、なるべく避ける（重なったときは画面が知らせます）
  2. ノートを エクスプローラーで移動・名前変更しない。アーカイブは「アーカイブ」の画面で（6章）
  3. Vault はいつも同じ場所から開く（7章）
  4. ノートは直接書き換えず、プラグインの画面から変える。手で表を直すと全部の行が変わったことになり、ほかの人の変更とぶつかりやすくなります

こんな知らせが出たとき

フォームで「フォームを開いた時からノートに更新があります」

開いている間に、ほかの人か別の画面でノートが変えられています。表の「保存後」の列（色の付いた値が変わる）を確かめてから選んでください。

変えた項目だけ上書きふつうはこれ。ほかの人の変更は残ります
フォームの内容ですべて保存ほかの人の変更も元に戻ります
開き直す入力を捨て、今のノートの値で開き直します
フォームに戻る入力したまま戻ります
表やチェックリストの画面で「画面を開いたあとに変わっています」

あなたの変更は保存されていません。画面を開き直し、今の内容を確かめてから入力し直してください。

設定画面で「共有設定が、ほかの人に変えられていました」

あなたの変更は保存されていません。画面は最新になっているので、確かめてからもう一度変えてください。色の設定は変えた項目だけを保存し、同じ項目はあとから保存した人の値になります。

間違えて消した・壊したとき

消したノートは Vault の中のごみ箱（.trash フォルダ）に残ります。戻せないときは管理者に連絡してください。

プラグインが新しくなったと知らせがあったとき

Obsidian をいったん閉じて開き直してください。開き直すまでは古いまま動きます。

  • ステータスごとの色（表とレポートの枠）
  • 開いているタブの並び
  • 設定 → Project Manager の見出し（▶／▼）で開け閉めできます
  • 色を選んでいないステータスは分類の色：未着手 進行中 完了 停止（↺ で戻せます）
  • Vault はいつも同じ場所から開いてください（Z:\… と \\server\… のように変えると、設定が初めに戻ります）

レイアウト（タブの並び）を保存して切り替える

タブの並びは全員で共有なので、自分の並びに名前を付けてこのパソコンに保存しておけます。

1タブを並べる
→
2「レイアウトを保存」名前を入れる（同じ名前は上書き）
→
3「レイアウトを切り替え」Obsidian を開いたあとなどに名前を選ぶ

「レイアウトを削除」で消せます（開いているタブはそのまま）。絞り込みは一緒に戻りません。
